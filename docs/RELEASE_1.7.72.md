# Strażnik 1.7.72 — GROTA po angielsku i ukraińsku

- GROTA mówi po angielsku i ukraińsku (Zasady → „Język · Language · Мова”; domyślnie język Strażnika albo telefonu). Instrukcja GROTY: po polsku, angielsku i ukraińsku.
- Po pobraniu mapy offline jednego województwa mapa GROTY poza nim traciła ulice, nawet z internetem — naprawione, bez ponownego pobierania mapy.
- Rozwinięte sekcje w GROCIE nie zwijają się same.
- Aplikacji nie da się przypadkiem powiększyć dwoma palcami (mapa przybliża się jak dotąd).
- Poprawione przesunięte podpisy w angielskim menu „More”.
