# Strażnik 1.7.12

- Bezpieczniejsze połączenia: zewnętrzne serwery wymagają HTTPS, aplikacja ufa wyłącznie systemowym urzędom certyfikacji.
- Własny adres HTTP nie jest zapisywany; wcześniej zapisany niepoprawny adres wymaga poprawienia w ustawieniach.
- Zachowany lokalny adres interfejsu i ustawienia użytkownika podczas aktualizacji.
- Poprawiona instrukcja instalacji, aktualizacji i uprawnień Androida.
- Bez zmian punktacji i progów alarmów.

To zwykła aktualizacja — można wybrać „Później”. Android wymaga potwierdzenia instalacji.
Po aktualizacji sprawdź zgody na powiadomienia i pełny ekran. Przy sieci przechwytującej HTTPS certyfikatem użytkownika połączenie może zostać odrzucone; nie wyłączaj weryfikacji certyfikatów.

Strażnik jest narzędziem dodatkowym, nie zastępuje RCB, RSO ani syren. Testy na emulatorze Pixel 7 nie gwarantują dostarczenia alarmu na każdym telefonie.
