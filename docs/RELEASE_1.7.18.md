# Strażnik 1.7.18 — zweryfikowane fotografie modeli

- Lokalne, zweryfikowane fotografie modeli samolotów i śmigłowców zamiast
  pobierania przypadkowego zdjęcia po krótkiej rejestracji.
- Naprawiony dobór PZ3T/019 oraz udokumentowanego Z42/0543/4984f4.
- 60 fotografii z podpisami PL/EN, autorami i licencjami; nie przedstawiają
  konkretnego śledzonego egzemplarza. Przy nieznanym albo sprzecznym wariancie
  karta wyświetla brak zweryfikowanego zdjęcia.
- Bez zmian ikon mapy, klasyfikacji maszyn, punktacji i wysyłania alarmów.
