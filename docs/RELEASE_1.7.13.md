# Strażnik 1.7.13

- Historia zapisuje wejścia i wyjścia rosyjskich oraz białoruskich maszyn ADS-B wraz z ostatnią pozycją.
- Krótkotrwała maszyna wykryta pomiędzy dwuminutowymi migawkami nie znika już z historycznej mapy.
- Pozycja odtworzona ze zdarzenia jest półprzezroczysta, aby nie udawała zwykłej migawki.
- Bez dodatkowych zapytań do źródeł i bez wpływu na punktację lub alarmy.

To zwykła aktualizacja — można wybrać „Później”. Strażnik jest źródłem dodatkowym i nie zastępuje RCB, RSO ani syren.
