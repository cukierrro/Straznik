# Strażnik 1.7.16

- Uzupełniono angielskie opisy samolotów wojskowych: przeznaczenie, kraj rejestracji, wysokość, prędkość, kurs, telemetrię i śledzenie trasy.
- Przetłumaczono widok obcych maszyn oraz brakujące objaśnienia samolotów i śmigłowców w legendzie.
- Etykieta wybranego województwa pokazuje teraz „my region” w angielskim interfejsie.
- Nazwy państw, miast i regionów na mapie są wyświetlane po angielsku, jeśli wybrano język angielski; brakujące nazwy zachowują bezpieczną nazwę źródłową.
