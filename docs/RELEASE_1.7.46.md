# Strażnik 1.7.46 — płynniejsza historia i start MiG-31K jako komunikat

- Historia mapy: migawki co minutę zamiast co dwie minuty, więc obiekty przy przewijaniu nie przeskakują tak daleko.
- Start MiG-31K ogłoszony przez NEPTUN dla całej Ukrainy („zagrożenie ogólnokrajowe”) jest komunikatem nad paskiem województwa, na żywo i w historii. Wcześniej wyglądał jak samolot stojący w środku Ukrainy, bo NEPTUN podaje wtedy umowny punkt, a nie pozycję maszyny.
- Taki alarm nie dolicza punktów dla Polski. Maszyna zgłoszona w konkretnym miejscu (z własnym obwodem) nadal jest zwykłym obiektem na mapie i punktuje jak dotąd.
