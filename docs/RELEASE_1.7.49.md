# Strażnik 1.7.49 — mniej fałszywych sygnałów z mediów

- Odnośniki do innych artykułów w opisie RSS („CZYTAJ: …”, „ZOBACZ TAKŻE: …”) nie są już traktowane jak treść wpisu. 14 września artykuł o oszuście z Radia Lublin dostał 0,5 pkt, bo w opisie był polecany tekst o ataku dronów.
- Miesiąc „września” / „wrześniu” nie jest już brany za miasto Września — daty nie przypisują artykułów do województwa wielkopolskiego. Miasto nadal jest rozpoznawane w formie „we Wrześni”.
- Obie poprawki działają na serwerze od razu po wdrożeniu; w aplikacji dotyczą trybu awaryjnego (gdy telefon sam liczy punkty).
